# ДЗ №5: Вычислительная геометрия

## Описание

Утилита для анализа географических данных. Данные заранее подготовлены и клонированы из репозитория https://github.com/mrTimofey/module-5-hw-data

Реализует алгоритмы вычислительной геометрии для обработки точек объектов и границ административных районов.

### Возможности

- Проекция координат из градусов в метры 
- Построение выпуклой оболочки 
- Поиск ближайшей пары точек 
- Подсчёт объектов внутри района
- Визуализация результатов на карте
- Независимая проверка 

## Установка
bash
git clone https://github.com/yakov19864/hw5-shell
cd hw5-shell
pip install -r requirements.txt

## Использование

Команды запускаются из корневой папки проекта. Исходные данные находятся в папке `data/data/`

### Подготовка данных

Координаты переводятся в метры, в корневой папке создаются `points.txt` и `district.txt`

### Выпуклая оболочка
python main.py hull points.txt
python main.py closest points.txt --brute  # O(N²), для проверки

### Точек внутри района
python main.py inside points.txt district.txt

### Визуал - созраняется в out/map.png

### Проверка (Shapely)
python verify/check_shapely.py
